    FURIVE OS · Furive 지원 차량용 소프트웨어 운영 기반

    자율주행을 더 빨리 개선하고,
    차량에 원격 업데이트하세요.¶

    Furive OS는 Furive 지원 차량에 탑재되어 자율주행(Autoware)·데이터 로깅·조작 UI 등 다양한 프로그램을 실행하고 관리합니다. 반복되는 설치·배포 작업을 줄이고, 더 어려운 주행 문제를 해결하는 데 집중하세요.

    가이드 바로가기 ↗ 실제 사용 영상 보기 ↓

    쓰던 GitHub 저장소 · 언어 · 프레임워크 그대로

    개발 → 자동 검사 → 원격 배포 → 차량 실행

    01 / 기존 개발 환경

    쓰던 GitHub 저장소 그대로¶

    개발 언어와 프레임워크를 바꾸지 않고, 각 팀의 프로그램을 차량에 연결합니다.

    02 / 원격 업데이트

    차량에 직접 가지 않고 배포¶

    문제를 고칠 때마다 새 버전을 원격으로 전달합니다. 차량에 직접 설치하러 가는 반복 작업을 줄입니다.

    03 / 차량 운영

    실행부터 상태 확인·복구까지¶

    차량별 프로그램과 버전을 확인하고, 업데이트 후 정상 확인에 실패하면 이전 정상판으로 복구합니다.

    자율주행 기능을 개선하는 과정

    늦게 감속하는 문제를 고쳐,
    시험 차량에 원격 배포합니다.¶

    개발팀은 감속 코드를 수정합니다. Furive OS는 새 버전을 차량에 전달하고, 검증·실행·복구를 맡습니다.

    개발·배포 흐름을 압축한 모션

    01 · 개발자의 PC

    보행자를 감지한 뒤,
    더 일찍 감속하도록 수정합니다.¶

    쓰던 GitHub 저장소와 편집기에서 자율주행(Autoware) 코드를 고칩니다. 보행자 이동 경로와 차량 속도를 반영하고, 수정한 코드를 푸시(Push)합니다.

    개발 가이드 바로가기 ↗

    02 · CI/CD 서버

    검사를 자동으로 반복하고,
    배포할 버전을 만듭니다.¶

    GitHub에 반영한 코드를 CI/CD 서버가 가져옵니다. 빌드와 자동 테스트로 변경 내용을 확인하고, 차량 업데이트 경로도 검사합니다. 통과한 배포본에는 전자서명을 붙여, 차량이 출처와 내용을 확인할 수 있게 합니다.

    서버에서 자동으로 확인하는 항목 ↗

    03 · 클라우드에서 차량으로

    고친 기능을 차량에 전달하고,
    새 버전으로 실행합니다.¶

    차량의 Furive OS가 새 버전을 내려받아 서명·내용·적용 대상을 검증합니다. 정차한 정비 시점에 적용하고, 실행 상태까지 확인합니다.

    문제를 고치거나 기능을 추가할 때마다 같은 과정으로 배포합니다. 정상 확인에 실패하면 이전 정상판으로 복구합니다.

    원격 업데이트 가이드 바로가기 ↗

    04 · 원격 배포 후, 같은 상황에서 확인

    바꾼 코드가 차량에서도
    의도한 대로 동작하는지 확인합니다.¶

    차량에 적용한 버전으로 같은 보행자 상황을 다시 시험합니다. 아래 모션에서 업데이트 전·후의 감속 시점과 정지 위치를 비교하세요.

    코드 수정 → 검사 → Furive OS 원격 배포 → 감속·정차 확인

    한 번의 배포로 끝나지 않습니다

    반복 작업을 줄여, 더 어려운 주행 문제에 집중합니다.¶

    시험에서 발견한 문제를 고치고, 다시 배포하고, 차량에서 확인합니다. 이 반복을 빠르게 이어가며 자율주행의 완성도를 높여갑니다.

    검증하고 실행·복구¶

    서명·내용·호환성을 검사하고, 적용 후 실행 상태에 따라 확정하거나 복구합니다.

    명령어 찾기¶

    프로그램 실행부터 자율주행, 업데이트, 데이터 로깅까지. 명령어와 실행 대상, 적용 조건을 함께 확인하세요.

    명령어 검색·전체 표 →

    TERMINAL 설치된 PC에서

    furive help       # 이 PC에서 가능한 작업
furive status     # 전체 운용 상태

    어디서 시작할지 모르겠다면 이 두 명령부터. PC 배정은 설치 상태를 자동으로 사용합니다.

    📦 패키지 🚘 자율주행 🔄 업데이트 🖥️ 시스템 📡 데이터 로깅

    화면으로 익히는 운용¶

    조작 UI에서 상태를 확인하고 필요한 작업을 진행하세요.

    🎥 DLS — 데이터 로깅·세션·재생 · 🚐 MGMT — 차량 상태·진단 · 🗺️ HMI — 주행 정보·3D 인지

    화면은 사용 설명서용 예시입니다. 실제 표시 내용은 설치 버전과 차량 플랫폼에 따라 달라집니다.
