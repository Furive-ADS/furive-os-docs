    FURIVE OS · 차량 소프트웨어 배포·실행 관리

    자율주행을 더 빨리 개선하고,
    차량에 원격 업데이트하세요.¶

    Furive OS는 Furive 지원 차량의 소프트웨어 배포·실행을 관리합니다. 팀이 만든 프로그램을 원격으로 업데이트하고, 차량에서 실행·상태 확인·복구까지 맡습니다.

    01 · 이슈 발견

    갑작스러운 무단횡단,
    감속이 늦었습니다.¶

    적색 보행자 신호에도 사람이 횡단보도로 들어옵니다. 차량이 늦게 감속해 보행자 가까이서 멈춥니다.

    02 · 코드 수정

    더 일찍 감속하도록
    코드를 고칩니다.¶

    쓰던 편집기에서 감속 코드를 수정하고, 커밋한 뒤 GitHub에 푸시합니다.

    개발 가이드 ↗

    03 · CI/CD 자동 검사

    검사는 서버에 맡기고,
    배포할 버전을 만듭니다.¶

    CI/CD 서버가 빌드·테스트를 실행하고, 통과한 버전에 서명합니다.

    자동 검사 범위 ↗

    04 · Furive OS 원격 배포

    수정한 기능을
    차량까지 원격으로.¶

    차량의 Furive OS가 새 버전을 검증하고 정차한 정비 시점에 적용·실행합니다. 정상 실행에 실패하면 이전 정상 버전으로 복구합니다.

    원격 업데이트 가이드 ↗

    05 · 개선 확인

    같은 상황에서도,
    이제 여유 있게 멈춥니다.¶

    Furive OS로 새 버전을 배포한 차량이 보행자를 감지하고 더 일찍 감속합니다. 수정 → 검사 → 배포 → 주행 확인, 이 과정을 빠르게 반복합니다.

    01 / 05
    반복 배포 · 여러 차량에 병렬로

    개선할 때마다,
    여러 차량에 새 버전을.

    코드를 고치고 검사하면, 여러 Furive 지원 차량으로 병렬 배포합니다. 주행 데이터를 로깅하고, 발견한 문제를 다음 업데이트에 반영합니다.
