    Autoware 플랫폼 탐색¶

    이 문서는 main의 Autoware 실행 화면이 차량 모델과 센서 모델을 찾는 순서를 설명합니다. 일반적인 플랫폼 추가 절차는 차량 플랫폼 만들기를 따릅니다.

    정상 경로에서는 사용자가 탐색 위치를 설정하지 않습니다. 같은 이름의 <플랫폼>_vehicle과 <플랫폼>_sensor_kit이 하나씩 있으면 자동 선택됩니다. 아래 환경변수와 선택 파일은 자동 탐색이 실패하거나 여러 플랫폼이 함께 발견됐을 때만 확인합니다.

    선택 순서¶

    flowchart TD
  Saved{"💾 저장된 선택이<br/>있는가?"}
  Saved -->|예| UseSaved["✅ 저장된 플랫폼 사용"]
  Saved -->|아니요| Env{"⚙️ 환경변수로<br/>지정했는가?"}
  Env -->|예| UseEnv["✅ 지정한 플랫폼 사용"]
  Env -->|아니요| Scan["🔍 Autoware 폴더 자동 탐색"]
  Scan --> Count{"❓ 발견된 플랫폼 수"}
  Count -->|0개| Error["❌ 선택 불가 오류"]
  Count -->|1개| Auto["✅ 자동 선택"]
  Count -->|여러 개| UI["🖥️ 운영 화면에서 선택"]

    정확한 우선순위는 다음과 같습니다.

    1. FURIVE_SELECTED_PLATFORM_FILE이 가리키는 파일의 값
    2. FURIVE_AUTOWARE_PLATFORM 환경변수
    3. Autoware 폴더 자동 탐색 결과

    기본 선택 파일은 $FURIVE_AUTOWARE_DIR/scripts/selected_platform.txt입니다.

    자동 탐색 규칙¶

    다음 경로를 순서대로 찾습니다.

    $FURIVE_AUTOWARE_DIR/furive_autoware_main/src
$FURIVE_AUTOWARE_DIR/src
$FURIVE_AUTOWARE_DIR

    전체 탐색 경로를 직접 지정할 때는 FURIVE_AUTOWARE_PLATFORM_DIRS에 :로 구분해 넣습니다. 이 값이 있으면 기본 목록을 대체하므로 기본 경로도 계속 찾으려면 함께 포함해야 합니다.

    export FURIVE_AUTOWARE_PLATFORM_DIRS="$HOME/Documents/Autoware/furive_autoware_main/src:$HOME/extra_autoware/src"

    같은 이름의 차량 모델과 센서 모델이 모두 있어야 플랫폼 하나로 인식합니다.

    <플랫폼>_vehicle
<플랫폼>_sensor_kit

    예를 들어 다음 두 폴더가 있으면 플랫폼 이름은 ioniq5입니다.

    furive_autoware_main/src/vehicle/ioniq5_vehicle
furive_autoware_main/src/sensor/ioniq5_sensor_kit

    Autoware 실행에는 다음 모델 이름이 전달됩니다.

    vehicle_model:=ioniq5_vehicle
sensor_model:=ioniq5_sensor_kit

    여러 플랫폼이 발견된 경우¶

    운영 화면에서 하나를 선택합니다. 선택한 이름은 selected_platform.txt에 저장되어 다음 실행에도 사용됩니다.

    지도 선택¶

    지도는 $FURIVE_AUTOWARE_DIR/furive_map 아래 폴더를 찾습니다. 선택한 지도는 기본적으로 $FURIVE_AUTOWARE_DIR/scripts/selected_map.txt에 저장됩니다.
